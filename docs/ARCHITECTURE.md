# Architecture

## Application layers

- `lib/main.dart` contains the Flutter application shell, responsive navigation, dashboard, calculator, record history, backup actions, and screenshot/OCR review flow.
- `Entry` is the persisted financial record model. Monetary values are serialized as decimal strings to avoid JSON floating-point conversion.
- The `decimal` package handles exact finite decimal operations. Ratios are kept rational until a display/tax amount needs a two-decimal result.
- `shared_preferences` stores the record collection and selected display currency locally.
- `file_picker` handles image selection, JSON backup import, and CSV/JSON export.
- Google ML Kit handles Latin-script OCR on Android/iOS. Desktop builds call the local Tesseract executable.

## Financial definitions

- Gross profit = revenue − cost of goods sold.
- Gross margin = gross profit ÷ revenue × 100.
- Contribution margin ratio = (revenue − cost of goods sold) ÷ revenue.
- Break-even revenue = operating expenses ÷ contribution margin ratio.
- Estimated tax = max(net profit before tax, 0) × entered tax rate.
- Estimated net profit after tax = net profit before tax − estimated tax.

Break-even is unavailable when revenue or contribution margin is zero or negative. Tax is a user-supplied estimate, not a tax determination.

## Data and privacy

The application has no backend, account system, analytics SDK, or network API. Saved records remain in app-local preferences. The user can export CSV for spreadsheet use or JSON for backup/restore. Imported backups are validated and can be merged or replace existing records.

OCR runs locally: ML Kit on mobile and Tesseract on desktop. No image is uploaded by Calru. The file picker accesses only the image or backup selected by the user.

## Platform generation

Native Flutter platform folders are generated by `tool/bootstrap_platforms.sh` with a stable Android/iOS bundle identifier. Generated platform projects are not committed, keeping the repository small. Build automation generates them before validation/building.
